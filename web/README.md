# 听歌统计报告页（纯前端）

单文件页面：`index.html`。数据来自插件（本地报告）或接收端（在线页），**页面本身零第三方依赖、不联网**（除同源读取 `report-data.json`）。

## 两种用法，同一份页面

| 用法 | 数据怎么来 | 二维码 |
|---|---|---|
| **本地报告**（默认） | 插件把数据**内联**进页面（`<script id="spw-inline-data">`），双击文件即可看 | 自动隐藏（本地文件扫码无意义） |
| **在线页**（可选扩展） | 同源 `fetch('./report-data.json')`，由 `receiver/` 生成 | 显示，指向本页真实地址 |

页面会自动判断：内联数据存在就用内联数据，否则拉取 `report-data.json`。

## 改了页面之后（**必须**跑构建）

`index.html` 是**源文件**，直接用 `cp` 部署会丢掉二维码。正确流程：

```bash
pip install qrcode                      # 仅这一步需要（构建期依赖）

python3 tools/build-report-page.py \
  index.html \
  <输出目录>/index.html \
  http://<你的服务器>:8123/spw-report/   # 二维码内容 = 报告页真实地址
```

然后把源文件复制成**插件内置模板**（本地报告用的就是它），并升插件版本号：

```bash
cp web/index.html plugin/src/main/resources/web/report.html
```

> 两者必须保持一致：在线页与本地报告是同一份页面，只是数据来源不同。

## 页面包含什么

- 顶部：累计时长、数据新鲜度（最后上报多久前，超 30 分钟变黄、超 2 小时变红）
- 每日时长：近 7 天 / 近 30 天 / 全部（标题显示区间合计）
- 常听艺人（多艺人拆分）、听得最多（搜索 + 展开全部）、**最近播放**（逐条会话明细，标注长曲目分段）
- 右上角 **⟳**：在线页重新取数（60 秒自动刷新、仅页面可见时），本地报告重新读取磁盘文件
- 夜间模式跟随系统，可手动切换并记忆
